# 贡献指南

感谢你关注本项目！参与贡献前请先阅读以下流程。

## 参与方式

- 发现缺陷或有功能建议：先在 Issue 区搜索是否已有相同讨论；没有则新建 Issue 描述清楚复现步骤或需求场景。
- 准备修改代码：Fork 本仓库，在自己的副本上新建分支进行开发。
- 提交改动：完成后发起 Pull Request，说明改动内容、动机与测试情况。

## 提交前检查

1. 代码风格保持与现有文件一致；
2. 本地运行 `python src/schedule.py` 确认功能正常；
3. 不提交 `__pycache__`、临时数据等无关文件。

## 行为准则

讨论应保持友善、就事论事，尊重不同意见。
